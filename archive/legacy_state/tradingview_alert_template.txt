============================================================
  TradingView Alert Setup Guide
  Copy-paste these into your TradingView alerts
============================================================

STEP 1: Create Alert in TradingView
-------------------------------------
Chart pe right-click → Add Alert
ya top bar mein "Alert" button click karo

STEP 2: Alert Settings
-------------------------------------
Condition: Apna indicator select karo
  → THE PHOENIX ya SuperBollingerTrend
  → "Buy Signal" condition select karo

STEP 3: Webhook URL field mein paste karo:
-------------------------------------
  https://YOUR-NGROK-URL/webhook

  (ngrok URL start karne ke baad milti hai)
  Example: https://abc123.ngrok-free.app/webhook

STEP 4: Message field mein paste karo (BUY alert ke liye):
-------------------------------------
{
  "key": "xauusd2024",
  "action": "BUY",
  "symbol": "XAUUSD",
  "price": {{close}},
  "comment": "TV Phoenix BUY {{timenow}}"
}

STEP 5: Message field mein paste karo (SELL alert ke liye):
-------------------------------------
{
  "key": "xauusd2024",
  "action": "SELL",
  "symbol": "XAUUSD",
  "price": {{close}},
  "comment": "TV Phoenix SELL {{timenow}}"
}

STEP 6: Alert Options
-------------------------------------
  ✅ Webhook URL: checked
  ✅ Once Per Bar Close: recommended (5-min bar close pe signal)
  ✅ Expiry: Set to max (1 month ya more)

============================================================
  TradingView Variables (use in message if needed):
  {{close}}    = closing price
  {{open}}     = open price
  {{high}}     = high price
  {{low}}      = low price
  {{volume}}   = volume
  {{timenow}}  = current time
  {{ticker}}   = symbol name
  {{interval}} = timeframe
============================================================

ADVANCED: Custom SL/TP from TV (optional):
-------------------------------------
{
  "key": "xauusd2024",
  "action": "BUY",
  "symbol": "XAUUSD",
  "price": {{close}},
  "sl": {{plot_0}},
  "tp": {{plot_1}},
  "comment": "TV Signal {{timenow}}"
}
(replace plot_0/plot_1 with your indicator's SL/TP plot names)
