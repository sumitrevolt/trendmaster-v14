📚 3 Levels of AI Learning
Level 1: Statistical Learning
ALWAYS ACTIVE
Win rate per symbol, session hour, indicator combo. Adaptive thresholds that auto-adjust. Market regime detection (trending vs ranging).
Level 2: ML Pattern Recognition
AFTER 50+ TRADES
Decision Tree classifier predicts WIN/LOSS. Learns which feature combinations produce wins. Auto-adjusts confidence based on ML prediction.
Level 3: Auto-Management
AUTONOMOUS
Auto-disable symbols <35% win rate. Auto-boost >65% win rate. Auto-adjust thresholds per symbol. Blacklist bad session hours.

📸 TradeSnapshot — What's Captured at Entry
Every trade entry captures ALL market conditions for later ML analysis:
symbol — e.g. XAUUSD
direction — BUY/SELL
score — Signal strength (0-100)
confidence — AI confidence %
h1_trend — H1 trend direction
h4_trend — H4 trend direction
rsi — RSI value
adx — ADX strength
macd — MACD label
bb_state — Bollinger state
amd_phase — AMD phase
news — News sentiment
hour_utc — Session hour
institutional_dir — COT bias
killzone — Active killzone
volume_signal — Volume state
After trade closes → WIN/LOSS result linked back to snapshot → ML model trains on this data

🔄 Failover & Redundancy

Rate Limit Protection
OpenRouter: 4 keys rotation. Gemini: 10 keys = 300 RPM. Per-provider min delay enforcement (1-5 sec).
Offline Fallback
If ALL 7 providers fail, Claude Knowledge Base provides instant offline responses with pre-trained trading wisdom.
ML Model Independence
